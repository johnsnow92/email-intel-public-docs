This guide indexes the published Email Deliverability Intelligence API. It is generated only from the public API schema, not from private implementation files.

- [Interactive API reference](https://email-intel-api-production.up.railway.app/docs)

The upstream reference is authoritative for authentication, request bodies, response schemas, pricing and availability. An endpoint appearing in a schema does not establish that it is available on every plan or that an operation will succeed.

## Using the reference

Choose an endpoint in the [endpoint index](/endpoints), then open the linked upstream reference for the full contract. Requests that write data, connect an account, trigger a batch or consume credits should be made only with authorization for that action. This guide does not run API requests.
